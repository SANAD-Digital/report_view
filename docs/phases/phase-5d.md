# المرحلة 5د: الرسوم والتفصيل

**الوكلاء:** `frontend-dev` و `backend-dev` (للتفصيل)، ثم `reviewer`.

## المهام
1. عرض الرسوم بـ ECharts حسب التصميم، بألوان من متغيرات CSS، ويتحدث مع الفلاتر ومع تغيير الثيم.
2. رسم من النطاق المحدد (Integrated Charts): نافذة فيها الرسم ولوحة صغيرة لتغيير نوعه.
3. التفصيل:
   - أعمدة Link تفتح المستند في تبويب جديد أو حسب الإعدادات.
   - التفصيل المعرّف في الإعدادات يفتح درجاً جانبياً بتقرير آخر (ميزان المراجعة ← General Ledger للحساب والفترة)، عبر `api.run` نفسه وبصلاحياته.
4. تسميات عربية سليمة في الرسوم (بدون قص أو تداخل).

## شروط القبول
- [ ] أرقام الرسوم مطابقة للجدول لنفس الفلاتر
- [ ] التفصيل يحترم الصلاحيات (`rv_restricted` لا يفتح حساب شركة أخرى)
- [ ] لقطات بالعربية والإنجليزية وفاتح وداكن
- [ ] مراجعة `reviewer`: قبول
