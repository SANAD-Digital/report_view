# المرحلة 5هـ: البحث والمفضلة والحالات والتلميع

**الوكلاء:** `frontend-dev`، ثم `reviewer`.

## المهام
1. شريط البحث بنمط Odoo: الفلاتر النشطة كشرائح، وحذف آخر شريحة بـ Backspace.
2. واجهة العروض المحفوظة: حفظ، ومشاركة (خاص / أدوار / عام)، وتعيين افتراضي، وحذف.
3. الحالات: تحميل (هيكل رمادي)، لا نتائج مع توجيه، خطأ في التقرير مع التفاصيل، تقرير أكبر من الحد.
4. الجوال على عرض 390px: الملخص يتكدس، واللوحات أوراق سفلية، والجدول يمرّر أفقياً مع بقاء العمود المثبّت.
5. مراجعة شاملة لـ RTL والداكن وإمكانية الوصول (تباين، تركيز مرئي، عناوين aria).
