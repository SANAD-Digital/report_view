# المرحلة 5أ: أساسيات الجدول حسب التصميم

**الوكلاء:** `frontend-dev`، ثم `reviewer`.
**المرجع:** `reference/design/` وخريطة المكونات في `docs/architecture.md`.

## المهام
1. رموز التصميم (ألوان، خطوط، مسافات، فاتح وداكن) كمتغيرات CSS، وثيم Tabulator مبني عليها.
2. رؤوس الأعمدة المجمّعة، والأعمدة المثبّتة، وصف الإجمالي المثبّت أسفل الجدول.
3. صف الفلاتر العائمة: نصي، ونطاق أرقام، ونطاق تواريخ.
4. قائمة العمود: تثبيت، ضبط العرض تلقائياً، تجميع بهذا العمود، إخفاء، إعادة الضبط.
5. فلتر القيم (Set Filter): قائمة القيم الفريدة، بحث داخلها، تحديد الكل، وعدّاد.
6. لوحة التجميع أعلى الجدول: سحب الأعمدة إليها، وإعادة ترتيبها، وحذفها.
7. عمود التجميع التلقائي مع العدد، وصفوف مجاميع لكل مجموعة.

## شروط القبول
- [ ] لقطات شاشة لكل عنصر بجانب ما يقابله في التصميم، بالفاتح والداكن، و RTL و LTR
- [ ] كل الفلاتر والتجميع تنعكس في حالة العرض والرابط
- [ ] مجاميع المجموعات صحيحة (اختبار آلي على ميزان المراجعة وتقرير آخر)
- [ ] يعمل بلوحة المفاتيح: تنقل بين القوائم، و Escape يغلق، و Enter يطبق
- [ ] لا أخطاء في console، و Playwright يغطي كل عنصر
- [ ] مراجعة `reviewer`: قبول
