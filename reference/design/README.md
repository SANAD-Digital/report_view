# محرك عرض التقارير — ميزان المراجعة (Report View Engine)

نموذج أولي من Claude Design لمحرك عرض تقارير Frappe/ERPNext بديل عن frappe datatable.

## الملفات
- `Main.dc.html` — النموذج التفاعلي لسطح المكتب (الجدول، Pivot، الرسوم، كشف الحساب، تفاصيل المعاملة، مكون الفترة، الطباعة).
- `Mobile.dc.html` — عرض الجوال مع الأوراق السفلية.
- `States.dc.html` — حالات التحميل / لا نتائج / خطأ / الملخص.
- `Tokens.dc.html` — رموز التصميم والمكونات وربطها مع Tabulator.
- `rv.css` — طبقة CSS كاملة (ثيم فاتح/داكن، كثافة مريح/مضغوط، RTL) — هذا الملف هو أساس التنفيذ.
- `tb-data.js` — البيانات التجريبية (الحسابات، الأرصدة الافتتاحية، قيود GL) بصيغة مضغوطة.
- `canvas.json` — فهرس لوحة التصميم.

## ملاحظة
ملفات `.dc.html` بصيغة Design Component وتعمل داخل Claude Design (تحتاج `support.js` من بيئة العرض).
المنطق موجود في وسم `<script type="text/x-dc">` داخل كل ملف: الحساب من القيود، التجميع، الفلترة، Pivot، تحديد النطاق، والطباعة — ويمكن نقله إلى طبقة JS فوق Tabulator.
